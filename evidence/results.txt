Energies
========

Every number is in kcal/mol and is read from the file named under it.
Electrostatic values are shown twice: as each program prints them, and
after correcting to one common constant, which is the only correction
applied anywhere. See engines.txt.

  The ParmEd conversion route used here writes [ cmaptypes ] keyed on the five
  backbone atom types spanning phi and psi. All four residues here share those
  types, so the four per-residue maps collapse onto one and the conversion
  keeps only the first. That is a limit of the conversion route as it was
  used, not of the GROMACS file format; the residue-specific-atom-type
  workaround was not attempted. The two cells above are left blank rather than
  filled with a number that would look like a disagreement about physics. See
  F-06. Every other GROMACS value on this structure agrees with the rest to
  about 1e-06.
